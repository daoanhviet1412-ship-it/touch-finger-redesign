# Touch Finger — Website redesign preview

Bản thử nghiệm thiết kế lại website tĩnh của Trung Tâm Sinh Trắc Touch Finger.

- HTML/CSS/JavaScript thuần, không cần build command.
- Giữ nguyên ảnh gốc và tên khách hàng.
- Đây là repo preview, chưa dùng để đổi domain production.

## Preview local

Mở `index.html` bằng static server, ví dụ `python3 -m http.server 8080`.
